# Kanser TManager V4.0 - Kurulum ve Başlatma Kılavuzu

Hızlı başlatma ve kurulum için ana klasördeki **`Baslat.bat`** dosyasına çift tıklamanız yeterlidir.
Açılan menü üzerinden tüm kütüphaneleri otomatik kurabilir veya uygulamayı yorulmadan başlatabilirsiniz.

## Manuel Olarak Başlatmak İsterseniz:
Eğer komut satırını kullanmak isterseniz bulunduğunuz klasörde bir terminal veya PowerShell açıp aşağıdaki komut dizilimini kullanabilirsiniz:

1. Gerekli kütüphaneleri kurmak için:
`.\.venv\Scripts\python.exe -m pip install -r requirements.txt`

2. Uygulamayı çalıştırmak için:
`.\.venv\Scripts\python.exe ghost_joiner.py`
